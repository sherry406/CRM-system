# CRM-system
一个简易的客户关系管理系统，帮助销售团队管理客户信息和跟进记录。

## 🚀 功能特性

- **客户管理**：添加、查看、删除客户信息
- **跟进记录**：记录每次沟通内容，设置下次跟进时间
- **智能提醒**：自动显示近期需要跟进的客户
- **数据统计**：实时显示客户数量、跟进统计等
- **公司分布**：查看客户公司分布情况

## 🛠️ 技术栈

- **后端**：FastAPI (Python)
- **前端**：HTML + CSS + JavaScript
- **数据库**：SQLite
- **部署**：Uvicorn
